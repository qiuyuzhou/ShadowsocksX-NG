# Legacy

## 定位

`Legacy/` 保存即将重新实现的旧版 ShadowsocksX-NG。该目录已冻结，只作为新实现的参考来源。其中的代码、配置、资源、依赖和文档都可能反映历史状态，不代表当前需求或技术选择。

## 工作规则

- 默认将 Legacy 作为只读参考：围绕新实现的工作只阅读、搜索和对照 Legacy；新代码、修复、测试和文档写入新实现所在目录。
- 迁移行为时，先记录具体文件、符号或资源等证据，再结合当前需求和平台 API 决定是否复现；历史实现不是现行规范。
- 以新实现的构建、测试和运行结果作为验证依据。Legacy 的验证结果只能说明旧版本状态。
- 只有用户明确要求维护 Legacy 时才修改其中内容；改动限制在明确范围内，并说明它不会替代新实现工作。

## 迁移完成标准

涉及 Legacy 的迁移或参考任务完成时，说明：

- 参考了哪些 Legacy 文件、符号或资源；
- 新实现中的对应落点；
- 哪些行为被保留、调整或有意不迁移，以及原因；
- 新实现执行了哪些验证及其结果。
